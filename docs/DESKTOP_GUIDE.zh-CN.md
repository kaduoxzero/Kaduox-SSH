# Kaduox SSH 桌面版使用说明

[下载 Windows 版本](https://github.com/kaduoxzero/Kaduox-SSH/releases) · [项目首页](https://github.com/kaduoxzero/Kaduox-SSH)

## 安装与首次启动

Windows x64 用户下载 `Kaduox-SSH-0.33.0-rc.1-windows-x64-setup.exe`，可选择安装目录和中文/英文安装界面。安装包包含 WebView2 离线安装组件。单文件桌面 EXE 适合已有 WebView2 Runtime 的电脑，不包含个人主机配置。数据保存在当前 Windows 用户的应用数据目录，不随 EXE 移动。

本版本为未签名的预发布版，Windows 可能显示发行者未知。只从本项目 Releases 下载，并核对 SHA256SUMS.txt；不要为运行软件关闭系统安全防护。macOS/Linux 桌面包不在本次发行中。

初次打开是空主机列表，无演示服务器、密码或自动连接。右上角选择深色/浅色主题。`Ctrl K` 搜索主机名、地址或标签，Enter 打开对应终端。

## 保存主机并打开终端

1. 点击“添加主机”，填写显示名称（支持中文、空格及括号）、地址、SSH 端口和登录用户。
2. 选择用途：“目标机器”“专用中转”或“两者兼用”。专用中转单独放在下方区域；兼用机器放在目标区，也能加入跳板链。
3. 密码存入 Windows 凭据管理器。也可选择私钥或 SSH Agent；私钥口令不作为明文配置保存。
4. 保存后点击主机，客户端自动使用已保存认证信息连接。只有认证失败、凭据缺失等情况才需要补充输入。
5. 已连接时再次点击主机，或点击终端栏“＋”，会新增独立终端。各终端的工作目录、变量和输出相互独立；SSH 连接可以复用。

“×”只关闭一个终端；“断开”关闭该机器全部终端及转发。关闭客户端不会保存正在运行的终端状态。主机配置及凭据保留到你主动修改/删除。

左栏文件夹按钮创建逻辑文件夹，点击名称折叠，铅笔按钮重命名。在“编辑主机”的文件夹下拉框中移动主机。文件夹不是服务器上的实际目录；没有预设的生产环境或实验室分组。

## SSH 跳板链：在最终目标上配置

例如下面的地址只作示例，不是真实服务器：

```text
本机 → 中转 A (demo@192.0.2.10:22) → 目标 B (deploy@198.51.100.20:22)
```

先分别保存 A 和 B 及各自的凭据。将 A 设为专用中转或兼用，编辑 B，在 SSH 连接路径中新建链，将 A 加入跳板列表并保存 B。之后直接点击 B，客户端自动经过 A 连接 B，不用在终端里手工输入第二条 ssh。

最多 5 台中转加 1 台最终目标。按本机到目标的顺序排列中转；不要将最终目标重复放进列表。每段默认 SSH，使用对应机器自己的用户、端口和凭据。上游机器需能访问下游 SSH 端口，并允许 TCP 转发。修改配置后重连才会采用新路线。单纯 SSH 跳转不需要再创建端口转发。

## 主机密钥策略

主机密钥用来验证服务器身份，不是登录密码或私钥文件。

| 策略 | 含义 |
| --- | --- |
| 严格 | 仅连接已记录并匹配可信指纹的服务器。首次连接前需通过可信渠道核验和记录指纹。 |
| 首次信任 | 首次自动记录指纹，之后变化则拒绝连接；第一次仍应核对服务器身份。 |
| 不安全 | 不验证服务器身份，只适合隔离测试，存在被冒充风险。 |

指纹变化可能是重装也可能是攻击。先联系管理员核验，不能以切换“不安全”代替排查。

## 端口转发不是 Nginx

需要先有一个正在运行的目标服务。客户端不会替你启动网站、配置域名或提供负载均衡。

| 类型 | 方向 | 用途 |
| --- | --- | --- |
| 本地 -L | 本机监听 → SSH → 远端侧服务 | 从本机访问内网数据库/网站 |
| 远程 -R | 远端监听 → SSH → 本机侧服务 | 通过服务器访问本机已有服务 |
| SOCKS -D | 本机 SOCKS5 代理 → SSH → 远端网络 | 在应用内配置 SOCKS5 代理 |

默认只绑定 `127.0.0.1`，不会自动开放公网。若确实要把本机网站分享出去，应选择远程转发，在公网服务器监听；还需要管理员允许转发、设置适当 `GatewayPorts`、对外绑定并开放防火墙和安全组。本软件不会自动修改服务器配置。

SSH 仅加密隧道段，公网用户到监听端口的连接仍需服务自身的 HTTPS 和鉴权。不要公开数据库或无认证管理端口。关闭连接会停止转发。参考 [OpenSSH 转发说明](https://man.openbsd.org/ssh.1) 和 [GatewayPorts](https://man.openbsd.org/sshd_config.5#GatewayPorts)。

## 信息数据屏、SFTP 与运行记录

信息页打开后立即采集当前下拉框对象，之后每 10 秒刷新，仅对当前对象采集，切换对象或离开页面会停止旧采集。展示 CPU、内存、磁盘、网络及可用 GPU 指标；GPU 数据依赖硬件和驱动工具，未检测到不代表所有设备均已被枚举。跳板节点只能在具备相应连接能力时实际查询，不能将目标数据误认为中转数据。

SFTP 复用已连接的 SSH，支持浏览、上传和下载。权限以登录用户为准。运行记录持久保存在本地，每页 50 条，可滚动与翻页；记录显式执行命令、传输和连接等操作，不捕获终端逐键输入。显式命令及其错误内容可能敏感，不要把秘密拼进命令中；发布截图/日志前自行脱敏。

## Kaduox AI 运维助手

仅调用用户配置的 OpenAI-compatible `/chat/completions` 服务，不提供假离线回答。填写厂商名称、接口地址、API 密钥，可获取模型列表或手动填写模型名；不支持列模型的服务可直接手填。远程接口必须使用 HTTPS，本机回环 API 可用 HTTP。

密钥保存到系统凭据库，不写进 Git、主机配置或浏览器存储。默认不发送主机上下文；勾选后才向所选服务发送相应上下文。不要粘贴密码、私钥、令牌或未脱敏日志。AI 不会自动执行命令，输出建议需自行审核。

## MCP 接入 Agent

下载独立 `kaduox-ssh-mcp.exe`。在 Agent 的 MCP 配置中设置 stdio 命令，替换下面的示例路径：

```json
{
  "mcpServers": {
    "kaduox": {
      "command": "C:/Tools/Kaduox/kaduox-ssh-mcp.exe"
    }
  }
}
```

默认只读，使用当前用户的主机库；读写授权环境变量与工具清单见 [MCP 文档](MCP.md)。不要把密码或 API 密钥写入 Agent 配置；只给可信 Agent 必要权限。该程序由 Agent 启动后通过标准输入/输出通信，无需手动打开窗口。

## 本地数据与隐私

主机和跳板链保存在 `%APPDATA%/Kaduox-SSH/hosts.toml`；密码在 Windows 凭据管理器；桌面页面设置与缓存位于 `%LOCALAPPDATA%/com.kaduox.ssh`。运行记录路径见 [桌面工作流](DESKTOP_WORKFLOWS.md)。这些数据不会作为发行包的一部分打包，但在你的电脑上仍需妥善保护。删除配置前关闭客户端，避免旧进程回写。不要删除系统 `.ssh` 或其他软件的凭据来清理本软件。
