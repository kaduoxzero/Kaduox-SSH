# Kaduox-SSH v0.17

## Hashed OpenSSH host trust markers

v0.17 extends the v0.16 host certificate trust layer to understand OpenSSH `|1|salt|hash` host patterns on security marker lines.

Supported marker behavior:

- `@cert-authority |1|...` can authorize an OpenSSH host certificate when the hash matches the exact OpenSSH known-hosts target.
- `@revoked |1|...` revokes a matching plain host key or host-certificate signing CA before ordinary strict/insecure host-key policy is considered.
- Port 22 hashes the hostname target; non-standard ports hash OpenSSH's `[host]:port` target.
- Malformed hashed marker entries fail closed rather than being ignored.
- Clear-text wildcard and negated marker patterns retain their v0.16 behavior.

The hash compatibility algorithm is OpenSSH's legacy HashedKnownHosts format: HMAC-SHA1 with the per-entry salt stored in the public known_hosts line. It is used only for matching the public host identifier; host-key and certificate cryptographic verification remain unchanged.

The real OpenSSH integration fixture creates marker files in clear text and asks the system `ssh-keygen -H` to hash them. This keeps fixture generation independent from Kaduox-SSH's matcher and covers trusted hashed CAs plus hashed revoked CAs/host keys.
