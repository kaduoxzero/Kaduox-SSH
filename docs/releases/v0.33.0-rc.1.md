# Kaduox SSH v0.33.0-rc.1 · Windows 桌面预发布版

这次发行当前实际提供 Windows x64 原生桌面安装包、免安装桌面程序、独立 MCP 程序和中文桌面手册附件。CLI/TUI、daemon、fleet、inventory 工具包未作为本次 Release 附件单独发布。

## 下载哪一个？

- `Kaduox.SSH_0.33.0-rc.1_x64-setup.exe`：推荐给普通用户。可选择安装位置，包含 WebView2 离线安装组件。
- `Kaduox-SSH_0.33.0-rc.1_x64-portable.exe`：免安装桌面程序；电脑需已有 WebView2 Runtime。个人配置保存在当前用户的应用数据目录。
- `kaduox-ssh-mcp.exe`：只需 MCP 接口时可单独下载。
- `DESKTOP_GUIDE.zh-CN.md`：本次发布对应的中文桌面使用手册。
- CLI/TUI 工具包与 `SHA256SUMS.txt`：当前未作为本次 Release 附件发布。

本次产物未进行 Authenticode 签名，Windows 可能提示发行者未知。发布范围仅 Windows x64，不包含 Linux/macOS 桌面包。

## 主要功能与改进

- 深色/浅色主题、自定义应用图标，首次启动为空主机列表。
- 保存主机和系统凭据；点击主机自动连接，已连接时直接新增独立终端，“＋”也仅新建终端。
- 支持中文、空格及括号的显示名称；用户创建文件夹、折叠、重命名及移动主机。
- 将专用中转与目标分区展示；由用户决定主机用途，支持最多五台 SSH 跳板再到最终目标。
- CPU、GPU、内存、磁盘和网络数据屏，打开即采集，每 10 秒刷新当前对象。
- SFTP、SSH 本地/远程/SOCKS5 转发及可视化连接路径。
- 持久化运行记录，每页 50 条，可滚动和翻页。
- Kaduox AI 支持用户配置兼容厂商、获取模型列表、系统密钥存储和可选上下文授权。
- MCP stdio 接口默认只读，命令与文件传输需要显式授权。
- 内置中文使用说明、主机密钥策略解释、转发方向说明和 GitHub 入口。

## 验证与限制

本次使用本地 Windows 构建发布，未宣称 GitHub Actions 或跨平台发布门禁通过。前端 35 项、主机库 17 项、桌面后端 26 项自动测试通过，相关 Rust Clippy 与前端生产构建通过。需要真实远端凭据的三项桌面集成测试在本次发布检查中保持显式忽略；之前的五层跳板和独立终端验证记录见项目文档。

两个 Cargo.lock 的 cargo-audit 0.22.0 检查均未报告已知漏洞；依赖仍有撤回版本及非 Windows 图形依赖维护/健全性提示。Windows 最低 Rust 编译版本受到 Pageant 依赖约束；本次使用 Rust 1.98.0 构建，不宣称 Windows Rust 1.85 编译通过。干净 Windows 安装环境及所有第三方 AI 厂商尚未穷举验证。

软件不包含个人服务器、密码、API 密钥或用户数据文件。密码及 API 密钥由当前用户的系统凭据库保存。文件夹和主机角色使用更新后的主机库格式，请同步升级共用该主机库的旧 CLI/TUI/MCP 程序。
