# Kaduox SSH v0.33.0-rc.19 · AI 运维助手平台感知与纯桌面端发行

这次发行让 AI 运维助手识别目标系统类型（不再对 Windows 目标发 Linux 命令）、新增"严格批准"权限档、修复 Windows 远端输出的中文乱码与首次指标采集超时；发行渠道同步收敛为纯桌面端，仅保留 3 个资产。

## 下载哪一个？

- `Kaduox-SSH-0.33.0-rc.19-windows-x64-setup.exe`：推荐给 Windows 普通用户。可选择安装位置，包含 WebView2 离线安装组件。
- `Kaduox-SSH-0.33.0-rc.19-macos-universal.pkg`：macOS 安装包（Intel + Apple Silicon，macOS 11+）。未签名，首次运行请右键应用图标选择“打开”。
- `kaduox-ssh-mcp.exe`：只需 MCP 接口接入 Agent 时单独下载。

校验方式：GitHub 资产页面会为每个文件自动显示 SHA-256 摘要，可用 PowerShell `Get-FileHash -Algorithm SHA256 <文件>` 核对；不再单独发布校验和清单文件。

## 相对 rc.18 的主要变更

- **AI 运维助手平台感知**：绑定主机后，AI 在第一轮命令前即获知目标系统（连接时已探测的 Windows/Unix 结果），Windows 目标直接使用 `ver`、`tasklist`、`netstat` 等原生命令，不再误发 `ss`、`free`、`df` 等 Linux 命令；命令卡片显示目标平台徽标；系统提示词同步禁止 `$(...)`、反引号等子 shell 语法（客户端安全策略会拒绝）。
- **命令风险分类器平台化**：Windows 目标启用专属白名单（`ver`/`systeminfo`/`tasklist`/`netstat`/`findstr`/`ipconfig`/`sc query`/`reg query`/`route print`/`wmic get`/`powershell Get-*` 等只读）；新增 Windows 危险项拦截（`format C:`、`rd /s /q C:\`、`del /s /q C:\Windows`）；Unix 语义不变。
- **新增"严格批准"权限档**：三档可选——严格批准（所有命令含只读都需批准）/ 请求批准（默认，只读自动执行，修改/删除需批准）/ 全部权限（只读+修改自动执行，删除需批准）；帮助页与使用说明的文案与实际行为统一；待批准命令卡片显式标注"批准后才会执行"。
- **Windows 远端中文乱码修复**：命令执行输出按目标平台解码（Windows → GBK，Unix → UTF-8），`系统找不到指定的路径` 等错误不再显示为乱码；指标采集失败的 stderr 尾部片段同样按平台解码。
- **Windows 首次指标采集超时修复**：远程采集超时 8 秒提升到 15 秒；`nvidia-smi` 采集包进 3 秒超时的独立 Job，独显休眠唤醒不再拖垮整次采集（超时则本次不显示 GPU 数据）；前端首轮采集失败自动立即重试一次；本机采集的 `nvidia-smi` 改为异步执行加超时，不再阻塞终端/SFTP 共享的执行器。
- **发行渠道收敛为纯桌面端**：停止发布四平台 CLI 压缩包、独立桌面 EXE、Windows 命令行工具包、SPDX SBOM、SHA256SUMS 清单与 GitHub attestation；CLI 工具源码仍保留在仓库中可自行构建。发布资产固定为上述 3 个文件，数量不符即发布失败（fail closed）。

## 验证与限制

命令分类器全量回归（含新增 Windows 只读/危险用例与严格批准矩阵）、AI 平台注入断言、GBK 解码用例、桌面 Rust 测试（57 项）、前端测试（48 项）、`cargo test --workspace --locked`（280 项）、release 策略测试（18 项）全部通过。因 tag 含预发布后缀，按策略跳过原生签名；桌面与 macOS 产物未做平台签名，系统可能提示发行者未知。Windows 目标仍不支持 sudo 提权切换。

软件不包含个人服务器、密码、API 密钥或用户数据文件。密码及 API 密钥由系统凭据库保存（Windows 凭据管理器 / macOS 钥匙串）。若 MCP 程序与桌面端共用主机库，请与桌面客户端一起升级。
