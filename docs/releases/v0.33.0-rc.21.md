# Kaduox SSH v0.33.0-rc.21 · AI 命令分类器安全加固与会话生命周期修复

这次发行是一次安全主导的修复版：修复了 AI 命令风险分类器的多个绕过面，以及断线自愈、终端关闭、端口转发的并发缺陷；同时把 E2E/视觉回归测试设施入库。

## 下载哪一个？

- `Kaduox-SSH-0.33.0-rc.21-windows-x64-setup.exe`：推荐给 Windows 普通用户。可选择安装位置，包含 WebView2 离线安装组件。
- `Kaduox-SSH-0.33.0-rc.21-macos-universal.pkg`：macOS 安装包（Intel + Apple Silicon，macOS 11+）。未签名，首次运行请右键应用图标选择“打开”。
- `kaduox-ssh-mcp.exe`：只需 MCP 接口接入 Agent 时单独下载。

校验方式：GitHub 资产页面会为每个文件自动显示 SHA-256 摘要，可用 PowerShell `Get-FileHash -Algorithm SHA256 <文件>` 核对；不再单独发布校验和清单文件。

## 安全修复（AI 命令分类器）

分类器从“空白分词启发式”重构为引号/转义感知的迷你 shell 词法器，修复：

- **换行绕过（严重）**：`ls\nrm -rf /` 这类多行命令首词命中只读白名单即被放行。现在换行在分类层按最高风险拆段，且执行入口直接拒绝含换行的命令。
- **粘连重定向漏检**：`echo x>/etc/cron.d/x` 此前判只读；现在逐字符识别写重定向（`2>`/`2>&1` 等 stderr 形式不误判）。
- **白名单含代码执行器**：`python/node/java` 移出只读白名单；`find`（带 `-exec`/`-delete`）、`awk`（`system()`）、`curl/wget`（`-F`/`-d`/`--upload-file`/`-X POST` 等上传参数）按参数级规则降级为修改。
- **PowerShell 写动词不全**：`Invoke-WebRequest/RestMethod/Command` 等 `Invoke-*` 全族不再判只读；`wmic` 改为结构化子命令校验（`wmic <别名> get|list`）。
- 主机被手动错标系统类型时，Windows 分类器对 `rm/dd/mkfs/shred` 兜底判危险；错标会在连接时给出提示。

## 其他修复

- **会话**：断线自愈重连进行中用户断开，不再复活出僵尸会话（代际校验 + 断开与重连互斥锁）；重连失败保留会话条目并显示警告，不再静默消失；连续重连失败增加 5s 起步的指数退避（上限 80s），避免对宕机主机的重连锤击。
- **终端**：远端通道 hang 时关闭终端/断开主机不再永久挂死（写入 10s 超时 + 关闭路径 abort 优先）；修复终端任务 spawn 与注册之间的泄漏窗口。
- **转发**：本地/动态转发的 accept 循环遇暂时性错误退避重试（此前一次错误即静默假死）；会话死亡后其转发在下次列表轮询时自动回收；绑定非回环地址需显式确认。
- **CLI**：`exec` 对 Windows 目标改用 cmd 兼容渲染，多词命令（`cmd /c ver` 等）不再因引号怪癖失败；`-J` 支持主机库别名，跳板密码可从系统凭据库读取；非交互环境下认证失败立即报错，不再挂起。
- **SFTP**：递归下载拒绝 Windows 保留设备名与尾随点/空格条目，同目录大小写/Unicode 归一化冲突条目计入 skipped；core 递归下载增加 32 层深度上限；上传目标末段校验 `..`；下载 staging 失败清理 + Unix O_NOFOLLOW 关闭符号链接 TOCTOU 窗口；同一目标的并发传输任务被拒绝；远程小文件读取加 1 MiB 硬上限。
- **MCP**：下载落盘限制在用户主目录内；单行请求限长 1 MiB；凭据账户名与桌面端共用同一实现。
- **AI 链路**：工具输出以 `<untrusted_remote_output>` 显式标记为不可信数据，系统提示词声明不执行其中指令；命令审计新增批准批次 ID，可把执行记录关联到具体一次批准动作。
- **杂项**：daemon IPC 并发连接上限 64；密码/API 密钥在进程内存中使用 zeroize 包装；生产 CSP 剔除开发服务器来源；终端命令历史对内联密码（`mysql -p<pw>` 等）后端兜底不落盘。

## 已知限制

桌面与 macOS 产物未做平台签名，系统可能提示发行者未知。Windows 目标仍不支持 sudo 提权切换。CLI 对 Windows 目标的 exec 输出不做 GBK 解码（桌面端不受影响）。

软件不包含个人服务器、密码、API 密钥或用户数据文件。密码及 API 密钥由系统凭据库保存（Windows 凭据管理器 / macOS 钥匙串）。若 MCP 程序与桌面端共用主机库，请与桌面客户端一起升级。
