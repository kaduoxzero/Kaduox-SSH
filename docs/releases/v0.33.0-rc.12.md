# Kaduox SSH v0.33.0-rc.12 · Windows 桌面预发布版

这次发行提供 Windows x64 原生桌面客户端，以及匹配版本的 CLI/TUI 和 MCP 程序。

## 下载哪一个？

- `Kaduox-SSH-0.33.0-rc.12-windows-x64-setup.exe`：推荐给普通用户。可选择安装位置，包含 WebView2 离线安装组件。
- `Kaduox-SSH-0.33.0-rc.12-windows-x64.exe`：独立桌面程序；电脑需已有 WebView2 Runtime。个人配置保存在当前用户的应用数据目录。
- `Kaduox-SSH-0.33.0-rc.12-windows-x64-tools.zip`：包含 kssh、kssh-tui、kssh-fleet、kssh-inventory，供命令行使用。
- `kaduox-ssh-mcp.exe`：只需 MCP 接口时可单独下载。
- `SHA256SUMS.txt`：下载后核对文件完整性。

本次产物未进行 Authenticode 签名，Windows 可能提示发行者未知。发布范围仅 Windows x64，不包含 Linux/macOS 桌面包。

## 相对 rc.11 的主要变化

- **主机工作区布局修复**：未连接主机（无会话标签栏）时，终端与 SFTP 面板不再只占据内容高度、下方留出大片空白——两个面板现在固定到工作区的拉伸网格行，任何会话状态下都占满至状态栏。
- **浅色主题 AI 控件修复**：AI 输入区的权限模式/模型选择下拉框在浅色主题下不再显示为黑色块；AI 命令卡片、Markdown 表格/引用/代码块、批量批准栏的边框同步改为主题变量，原生下拉在浅色模式使用浅色配色。

## 工程整理

- AI 样式表去重：合并重复的 `.composer-footer` 定义与文件末尾的覆盖块；移除 AI 布局面板固定的 `min-height: 590px`，改为弹性布局。

## 验证与限制

本次使用本地 Windows 构建发布，未宣称 GitHub Actions 或跨平台发布门禁通过（CI 的 Release 流水线存在两个既有问题：Ubuntu 缺少 libdbus 系统依赖、SBOM 工具与工作区成员数量校验失配，rc.10/rc.11 相同）。前端 43 项自动测试通过，Rust 工作区 release 构建与前端生产构建通过，四个 CLI 二进制 `--version` 冒烟通过。需要真实远端凭据的三项桌面集成测试保持显式忽略。

软件不包含个人服务器、密码、API 密钥或用户数据文件。密码及 API 密钥由当前用户的系统凭据库保存。请同步升级共用该主机库的旧 CLI/TUI/MCP 程序。
