# Kaduox SSH v0.33.0-rc.20 · 修复远程 Windows 目标 GPU 采集

这次发行修复 rc.19 的一处回归：远程 Windows 目标（SSH 通道）的 GPU 指标整段缺失。

## 下载哪一个？

- `Kaduox-SSH-0.33.0-rc.20-windows-x64-setup.exe`：推荐给 Windows 普通用户。可选择安装位置，包含 WebView2 离线安装组件。
- `Kaduox-SSH-0.33.0-rc.20-macos-universal.pkg`：macOS 安装包（Intel + Apple Silicon，macOS 11+）。未签名，首次运行请右键应用图标选择“打开”。
- `kaduox-ssh-mcp.exe`：只需 MCP 接口接入 Agent 时单独下载。

校验方式：GitHub 资产页面会为每个文件自动显示 SHA-256 摘要，可用 PowerShell `Get-FileHash -Algorithm SHA256 <文件>` 核对；不再单独发布校验和清单文件。

## 相对 rc.19 的主要变更

- **修复远程 GPU 采集回归（rc.19 引入）**：`metrics.ps1` 把 `nvidia-smi` 包进带超时的后台 Job 时，Job 上下文把未加引号的逗号参数解析成数组，nvidia-smi 收到拆散的选项报错（`Option utilization.gpu is not recognized`），GPU 行整段缺失，远程目标显示"未检测到独立 GPU"。改为 Job 内显式引号传参，已在本机按生产同款 stdin 通道验证输出正常。本机采集路径不受影响。

## 验证与限制

桌面 Rust 测试（57 项）、发布脚本策略测试（18 项）全部通过；`metrics.ps1` 经 `powershell -Command -` stdin 通道实测输出 `gpu=` 行。桌面与 macOS 产物未做平台签名，系统可能提示发行者未知。Windows 目标仍不支持 sudo 提权切换。

软件不包含个人服务器、密码、API 密钥或用户数据文件。密码及 API 密钥由系统凭据库保存（Windows 凭据管理器 / macOS 钥匙串）。若 MCP 程序与桌面端共用主机库，请与桌面客户端一起升级。
