# Kaduox SSH v1.0.0 · 首个正式版

v1.0.0 是 Kaduox SSH 的首个正式稳定版，为 0.33.0 候选系列（rc.1–rc.21）画上句号。自 rc.21 起无代码变更，本版发布内容即 rc.21 构建的正式版晋升，语义化版本承诺自 1.0.0 起生效。

## 下载哪一个？

- `Kaduox-SSH-1.0.0-windows-x64-setup.exe`：推荐给 Windows 普通用户。可选择安装位置，包含 WebView2 离线安装组件。
- `Kaduox-SSH-1.0.0-macos-universal.pkg`：macOS 安装包（Intel + Apple Silicon，macOS 11+）。未签名，首次运行请右键应用图标选择"打开"。
- `kaduox-ssh-mcp.exe`：只需 MCP 接口接入 Agent 时单独下载。

校验方式：GitHub 资产页面会为每个文件自动显示 SHA-256 摘要，可用 PowerShell `Get-FileHash -Algorithm SHA256 <文件>` 核对；不再单独发布校验和清单文件。

## 1.0 功能全景

- **桌面 SSH 客户端**（Windows x64 / macOS Universal 2）：多会话终端与会话标签栏、按主机持久化的命令历史（敏感输入不落盘）、深色/浅色主题、中英双语界面。
- **主机库**：文件夹与专用跳板分区、中文/空格/括号显示名、密码存系统凭据库（Windows 凭据管理器 / macOS 钥匙串）、Agent 认证（Pageant / ssh-agent）、最多五跳跳板链、远端平台自动探测（Windows 目标显示徽标）。
- **终端**：Windows 目标交互式 cmd.exe/pwsh、GBK 中文输出解码、脚本经 stdin 通道下发（规避 cmd /c 8191 字符上限）、复制粘贴右键菜单。
- **SFTP**：浏览、上传/下载、递归文件夹下载（符号链接跳过、深度/总量上限）、断点续传、真实文件夹大小、小文件在线编辑、Windows 盘符路径、严格的路径穿越防护。
- **监控与转发**：CPU/GPU/内存/磁盘/网络数据屏（10 秒刷新，Windows 目标同样支持）、本地/远程/SOCKS5 端口转发与可视化路径。
- **AI 助手**：直连主机执行命令并回传分析，三档权限模式（严格批准/请求批准/全部权限），批量批准，危险命令任何模式下客户端直接拒绝，平台感知提示词（Windows 目标使用原生命令），按主机隔离的持久化对话，引号/转义感知的风险分类器。
- **MCP 接口**：默认只读，命令与文件传输需显式授权；与桌面端共用主机库时请同步升级。

## 安全说明

rc 系列完成了多轮安全加固：AI 命令分类器词法重构（修复换行/重定向粘连/子 shell 等注入绕过）、SFTP 递归下载路径校验、下载落盘限制在用户目录、exec 通道进程清理、断线重连退避与僵尸会话防护、daemon IPC 并发上限。密码与 API 密钥由系统凭据库保存，进程内存中使用 zeroize 包装；软件不捆绑任何个人服务器、密码或用户数据。

## 已知限制

- macOS 产物未做平台签名，系统可能提示发行者未知，首次运行右键打开即可。
- Windows 目标不支持 sudo 提权切换。
- CLI 对 Windows 目标的 exec 输出不做 GBK 解码（桌面端不受影响）。
- 发行不包含 Linux 桌面包。
