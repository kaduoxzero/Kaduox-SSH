# Kaduox SSH v0.33.0-rc.10 · Windows 桌面预发布版

这次发行提供 Windows x64 原生桌面客户端，以及匹配版本的 CLI/TUI 和 MCP 程序。

## 下载哪一个？

- `Kaduox-SSH-0.33.0-rc.10-windows-x64-setup.exe`：推荐给普通用户。可选择安装位置，包含 WebView2 离线安装组件。
- `Kaduox-SSH-0.33.0-rc.10-windows-x64.exe`：独立桌面程序；电脑需已有 WebView2 Runtime。个人配置保存在当前用户的应用数据目录。
- `Kaduox-SSH-0.33.0-rc.10-windows-x64-tools.zip`：包含 kssh、kssh-tui、kssh-fleet、kssh-inventory，供命令行使用。
- `kaduox-ssh-mcp.exe`：只需 MCP 接口时可单独下载。
- `SHA256SUMS.txt`：下载后核对文件完整性。

本次产物未进行 Authenticode 签名，Windows 可能提示发行者未知。发布范围仅 Windows x64，不包含 Linux/macOS 桌面包。

## 相对 rc.9 的主要变化

- **运行记录按机器筛选**：新增「记录主机」下拉，默认跟随当前选中的机器（切换会话标签/主机自动跟随），可手动切回「全部主机」；与按天筛选可叠加，分页与总数均按筛选后计算。已断开主机的历史记录同样可筛。
- **AI 会话按主机隔离**：AI 运维助手的会话列表只显示当前目标主机的会话；切换目标主机自动回到新会话，不会把 A 主机的对话带到 B 主机。新建会话归属当前目标；「不绑定远程主机」下的会话独立存在。旧版本的会话自动迁移为未绑定范围。

## 验证与限制

本次使用本地 Windows 构建发布，未宣称 GitHub Actions 或跨平台发布门禁通过。前端 39 项、桌面后端 43 项自动测试通过，Rust 工作区全量测试与前端生产构建通过。需要真实远端凭据的三项桌面集成测试保持显式忽略。

软件不包含个人服务器、密码、API 密钥或用户数据文件。密码及 API 密钥由当前用户的系统凭据库保存。请同步升级共用该主机库的旧 CLI/TUI/MCP 程序。
