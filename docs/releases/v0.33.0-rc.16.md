# Kaduox SSH v0.33.0-rc.16 · Windows 目标文件管理与信息面板

这次发行补全了 **Windows OpenSSH 目标主机** 的远程文件管理与系统信息面板，桌面安装包首次由 Release 流水线自动构建并附加。

## 下载哪一个？

- `Kaduox-SSH-0.33.0-rc.16-windows-x64-setup.exe`：推荐给 Windows 普通用户。可选择安装位置，包含 WebView2 离线安装组件。
- `Kaduox-SSH-0.33.0-rc.16-windows-x64.exe`：独立 Windows 桌面程序；电脑需已有 WebView2 Runtime。
- `Kaduox-SSH-0.33.0-rc.16-macos-universal.pkg`：macOS 安装包（Intel + Apple Silicon，macOS 11+）。未签名，首次运行请右键应用图标选择“打开”。
- `Kaduox-SSH-0.33.0-rc.16-windows-x64-tools.zip`：kssh、kssh-tui、kssh-fleet、kssh-inventory 命令行工具。
- `kaduox-ssh-mcp.exe`：只需 MCP 接口时单独下载。
- `kaduox-ssh-0.33.0-rc.16-<target>.tar.gz / .zip`：四平台 CLI 套件归档，含清单与 SBOM。
- `SHA256SUMS` / `SHA256SUMS.txt`：分别对应官方四平台资产和桌面附加资产。

## 相对 rc.15 的主要变化

- **Windows 目标文件管理**：SFTP 支持 `C:/...` 盘符路径，自动探测 `%USERPROFILE%` 真实 home 目录，文件管理门控解除；本机回环实测上传/下载/列目录通过。
- **Windows 目标信息面板**：新增 `metrics.ps1` 采集 CPU/内存/磁盘/网络/GPU（与 Linux 同一 wire 协议），UTF-8 直写字节流解决中文乱码；本机回环实测返回完整数据（含 GPU 型号）。
- **交互终端 pwsh 回退**：目标装有 PowerShell 7 时自动使用 pwsh，否则回退 cmd.exe。
- **桌面安装包并入 Release 流水线**：新增 desktop-windows / desktop-macos 构建 job 与 attach-desktop 附加 job，桌面资产随发布自动附加（保持官方 8 资产契约与发布后资格验证范围不变），不再手工上传。

## 验证与限制

Release 流水线四平台 CLI 构建、目标级 SBOM、桌面 Windows/macOS 构建与资产校验全部通过；因 tag 含预发布后缀，按策略跳过原生签名与 GitHub attestation。Windows 目标路径经 CI loopback OpenSSH 集成测试（探测、exec、sudo 拒绝、交互 shell 回显）与本机实测覆盖。桌面与 macOS 产物未做平台签名，系统可能提示发行者未知。Windows 目标仍不支持 sudo 提权切换（runas 需交互密码，暂无等价方案）。

软件不包含个人服务器、密码、API 密钥或用户数据文件。密码及 API 密钥由系统凭据库保存（Windows 凭据管理器 / macOS 钥匙串）。请同步升级共用该主机库的旧 CLI/TUI/MCP 程序。
