# Kaduox SSH v0.33.0-rc.13 · Windows 桌面预发布版

这次发行提供 Windows x64 原生桌面客户端，以及匹配版本的 CLI/TUI 和 MCP 程序。

## 下载哪一个？

- `Kaduox-SSH-0.33.0-rc.13-windows-x64-setup.exe`：推荐给普通用户。可选择安装位置，包含 WebView2 离线安装组件。
- `Kaduox-SSH-0.33.0-rc.13-windows-x64.exe`：独立桌面程序；电脑需已有 WebView2 Runtime。个人配置保存在当前用户的应用数据目录。
- `Kaduox-SSH-0.33.0-rc.13-windows-x64-tools.zip`：包含 kssh、kssh-tui、kssh-fleet、kssh-inventory，供命令行使用。
- `kaduox-ssh-mcp.exe`：只需 MCP 接口时可单独下载。
- `SHA256SUMS.txt`：下载后核对文件完整性。

本次产物未进行 Authenticode 签名，Windows 可能提示发行者未知。发布范围仅 Windows x64，不包含 Linux/macOS 桌面包。

## 相对 rc.12 的主要变化

- **远程文件列表修复**：文件夹的大小列不再显示服务器返回的垃圾值（如 "1016 MB"），统一显示 `—`；修改时间列补上了年份并加宽，不再截断。
- **文件夹真实大小**：属性弹窗打开时按需统计目录总大小。优先通过 `du -sb` 在服务器本地一次遍历完成（通常秒出）；服务器没有 `du` 或禁止 exec 时自动回退到 SFTP 并发遍历（同层 8 路），任何环境都能出结果。

## 验证与限制

本次使用本地 Windows 构建发布，未宣称 GitHub Actions 或跨平台发布门禁通过（CI 的 Release 流水线存在两个既有问题：Ubuntu 缺少 libdbus 系统依赖、SBOM 工具与工作区成员数量校验失配，rc.10/rc.11/rc.12 相同）。核心 crate 187 项自动测试通过，Rust 工作区 check 与前端类型检查通过。需要真实远端凭据的三项桌面集成测试保持显式忽略。

软件不包含个人服务器、密码、API 密钥或用户数据文件。密码及 API 密钥由当前用户的系统凭据库保存。请同步升级共用该主机库的旧 CLI/TUI/MCP 程序。
