# Kaduox SSH v0.33.0-rc.7 · Windows 桌面预发布版

这次发行提供 Windows x64 原生桌面客户端，以及匹配版本的 CLI/TUI 和 MCP 程序。

## 下载哪一个？

- `Kaduox-SSH-0.33.0-rc.7-windows-x64-setup.exe`：推荐给普通用户。可选择安装位置，包含 WebView2 离线安装组件。
- `Kaduox-SSH-0.33.0-rc.7-windows-x64.exe`：独立桌面程序；电脑需已有 WebView2 Runtime。个人配置保存在当前用户的应用数据目录。
- `Kaduox-SSH-0.33.0-rc.7-windows-x64-tools.zip`：包含 kssh、kssh-tui、kssh-fleet、kssh-inventory，供命令行使用。
- `kaduox-ssh-mcp.exe`：只需 MCP 接口时可单独下载。
- `SHA256SUMS.txt`：下载后核对文件完整性。

本次产物未进行 Authenticode 签名，Windows 可能提示发行者未知。发布范围仅 Windows x64，不包含 Linux/macOS 桌面包。

## 相对 rc.1 的主要变化

- 文件夹分组区分「目标主机 / 专用中转」两个区域，新建时选择归属；文件夹可删除（连同组内主机，带二次确认；被跳板链引用或有活跃会话时拒绝）。
- 新建主机保存后可自动发起首次连接（默认勾选）。
- 点击已连接主机只切换会话，不再自动新增终端；顶部新增会话标签栏列出全部连接，可切换、断开，➕ 为当前会话新增终端。
- 左侧「目标主机 / 专用中转」区域可折叠，共用一个滚动容器。
- 远程文件支持新建文件夹/文件、重命名、删除（仅空目录）、属性查看、在线编辑（≤1 MiB UTF-8 文本）与当前目录名称搜索。
- 会话栏新增命令历史面板：按主机持久化保存你在本软件中执行/输入过的命令（含终端里手敲的命令；密码、口令等敏感输入不记录），支持复制、编辑后再执行。
- 远程文件支持右键菜单：打开/编辑/下载/新建/重命名/属性/删除，空白处可新建、上传、刷新。
- 运行记录每行支持复制命令与编辑后重跑。
- 状态栏与帮助页显示当前软件版本（来自构建配置，不再硬编码）。
- 无边框窗口：顶部白色原生标题栏移除，窗口控制（最小化/最大化/关闭）合并进深色顶栏，顶栏可拖动、双击切换最大化。
- 移除用途不大的“聚焦终端”按钮。
- 运行记录升级：每条记录包含执行时的登录用户（显示为 `用户@主机`）；支持按天查询（日期选择器 + 今天/昨天/全部快捷按钮）；记录不可清空，“归档并清空”改为“创建归档快照”（仅备份，不删除任何记录）；终端里手敲的命令也进运行记录（标记“终端”来源，退出码/耗时显示“—”），命令栏执行的标记“命令栏”。
- 无边框窗口修复：顶栏整块可拖动（自实现拖拽，替代只在缝隙生效的原方案）、双击空白最大化/还原、窗口阴影恢复；修复右上角最小化/最大化/关闭按钮点击无反应（补充窗口控制权限）。
- 修复：SFTP 面板在新增搜索工具栏后行错位的问题。

## 验证与限制

本次使用本地 Windows 构建发布，未宣称 GitHub Actions 或跨平台发布门禁通过。前端 35 项、主机库 18 项、桌面后端 28 项自动测试通过，Rust 工作区全量测试与前端生产构建通过。需要真实远端凭据的三项桌面集成测试在本次发布检查中保持显式忽略；之前的五层跳板和独立终端验证记录见项目文档。

软件不包含个人服务器、密码、API 密钥或用户数据文件。密码及 API 密钥由当前用户的系统凭据库保存。主机库新增 `jump_folders` 键（向后兼容）；命令历史保存在主机库旁的 `command-history.jsonl`。请同步升级共用该主机库的旧 CLI/TUI/MCP 程序。
