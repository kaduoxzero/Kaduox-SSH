# Kaduox-SSH v1.2.0

**功能版本**：私钥口令可保存到系统凭据库——加密密钥连接一次输入，之后免密。

## 新增：私钥口令保存

此前每次用带口令（passphrase）的私钥连接都要重新输入口令；口令设计上不落盘，
断线自愈重连也无法自动完成，跳板机跳点更是完全不支持加密密钥。v1.2.0 起：

- 连接对话框私钥模式新增「连接成功后把口令保存到系统凭据库」复选框
  （**默认不勾选**，显式选择才保存）。
- 口令按**密钥文件路径**存入系统凭据库（`key:<规范化路径>` 账户，与主机密码
  同属 `kssh` service）：同一把密钥连多台主机只输一次口令，一处改处处生效。
- 已保存口令自动作用于：新建连接、断线自愈重连、**跳板链各跳**
  （此前跳板跳点写死无口令，加密密钥必失败，本次顺带修复）。
- 已保存时口令框提示「留空以使用已保存口令」，并可在对话框中一键删除。

## 安全语义

- 与已保存的主机密码同级保护：Windows 凭据管理器 / macOS 钥匙串 /
  Linux Secret Service，应用自身永不落盘。
- 凭据库口令仅用于**当初保存时的那个密钥文件路径**；显式输入的口令认证失败时
  绝不静默回退到已存口令；口令只在**认证成功后**写入。
- 桌面端、CLI、MCP 共用 core 的同一份凭据访问实现，无格式漂移面。

## 验证

- Rust workspace 与 desktop 单元测试全绿（新增 core 命名/存储、真 keyring 往返、
  前端 ConnectDialog 共 8 项新测试）。
- 真机冒烟（linx1）：临时加密 Ed25519 密钥全链路——部署公钥 → 存口令 →
  无口令连接成功 → 删除口令后 fail-closed → 清理。
- E2E 新增 08 组四步 GUI 冒烟（loopback 加密密钥：对话框输口令保存 →
  重连免输直达 → 删除后空口令报错），全套件 11 条通过。

## 已知限制

- RSA 私钥直连仍按 RUSTSEC-2023-0071 禁用（经 agent 可用），本功能同样适用。
- 密钥文件移动后旧路径的口令条目成为孤儿，可在连接对话框按新路径重新保存，
  旧条目不产生影响。
