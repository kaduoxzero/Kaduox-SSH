# Kaduox SSH v0.33.0-rc.8 · Windows 桌面预发布版

这次发行提供 Windows x64 原生桌面客户端，以及匹配版本的 CLI/TUI 和 MCP 程序。

## 下载哪一个？

- `Kaduox-SSH-0.33.0-rc.8-windows-x64-setup.exe`：推荐给普通用户。可选择安装位置，包含 WebView2 离线安装组件。
- `Kaduox-SSH-0.33.0-rc.8-windows-x64.exe`：独立桌面程序；电脑需已有 WebView2 Runtime。个人配置保存在当前用户的应用数据目录。
- `Kaduox-SSH-0.33.0-rc.8-windows-x64-tools.zip`：包含 kssh、kssh-tui、kssh-fleet、kssh-inventory，供命令行使用。
- `kaduox-ssh-mcp.exe`：只需 MCP 接口时可单独下载。
- `SHA256SUMS.txt`：下载后核对文件完整性。

本次产物未进行 Authenticode 签名，Windows 可能提示发行者未知。发布范围仅 Windows x64，不包含 Linux/macOS 桌面包。

## 相对 rc.7 的主要变化（Kaduox AI 运维助手增强）

- **AI 直连主机执行命令**：选择一台已连接的目标主机后，AI 可通过 `execute_command` 工具直接在该主机上执行排查命令，结果自动回传给 AI 继续分析。
- **Codex 风格双权限模式**：
  - 「请求批准」（默认）：只读命令（ls/df/ps/journalctl 等）自动执行；新增、修改、删除类命令逐条弹出批准卡片，由你手动批准后才执行。
  - 「全部权限」：只读与修改类命令自动执行，删除类命令仍需手动批准。开启前会弹出确认提醒。
  - 危险命令（fork 炸弹、`rm -rf /`、写裸盘、`mkfs` 等）在任何模式下都会被客户端直接拒绝。
- **命令留痕**：AI 执行的每条命令写入运行记录（新增紫色「AI」来源徽标），同时落入 `ai-chat.db` 的命令审计表（含风险级别、权限模式、是否经用户批准）。
- **对话记录持久化**：AI 会话保存在 `%APPDATA%\Kaduox-SSH\ai-chat.db`，左侧会话列表支持新建、切换、重命名、删除，重启客户端后对话仍在。
- **服务商删除**：服务商配置可删除（带二次确认），并联动清除系统凭据管理器中保存的 API 密钥；另提供「恢复默认服务商」。
