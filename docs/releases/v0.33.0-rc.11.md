# Kaduox SSH v0.33.0-rc.11 · Windows 桌面预发布版

这次发行提供 Windows x64 原生桌面客户端，以及匹配版本的 CLI/TUI 和 MCP 程序。

## 下载哪一个？

- `Kaduox-SSH-0.33.0-rc.11-windows-x64-setup.exe`：推荐给普通用户。可选择安装位置，包含 WebView2 离线安装组件。
- `Kaduox-SSH-0.33.0-rc.11-windows-x64.exe`：独立桌面程序；电脑需已有 WebView2 Runtime。个人配置保存在当前用户的应用数据目录。
- `Kaduox-SSH-0.33.0-rc.11-windows-x64-tools.zip`：包含 kssh、kssh-tui、kssh-fleet、kssh-inventory，供命令行使用。
- `kaduox-ssh-mcp.exe`：只需 MCP 接口时可单独下载。
- `SHA256SUMS.txt`：下载后核对文件完整性。

本次产物未进行 Authenticode 签名，Windows 可能提示发行者未知。发布范围仅 Windows x64，不包含 Linux/macOS 桌面包。

## 相对 rc.10 的主要变化

- **AI 输入区按键调整**：Enter 直接发送，Shift+Enter 换行（原为 Ctrl+Enter 发送）；提示文案同步更新；右上角设置按钮更名为「AI 厂商配置」。
- **终端粘贴修复**：修复 Ctrl+V 粘贴内容出现两份的问题（自定义按键处理与 xterm 原生 paste 事件竞态，现已正确阻止默认行为）。
- **运行记录页精简**：移除使用率低命令执行栏（主机下拉+输入框+执行并记录）和每行的「编辑并重跑」按钮，页面专注于按机器/按天浏览、筛选与复制记录。

## AI 执行链路修复

- **工具调用三级回退解析**：依次尝试原生 `tool_calls` → DSML 风格标记 → 纯文本 `command:` 行，修复部分模型输出伪调用文本时不出现命令批准卡片、对话静默停住的问题；系统提示同时注入绑定主机别名，抑制模型生成伪标记。
- **不支持 function calling 的模型自动降级**：带 tools 的请求收到 400 时自动以无 tools 方式重试，聊天不再直接失败。
- **长对话成对修剪**：前端修剪消息时不再拆散 assistant 与 tool 结果配对，并插入省略提示；后端消息上限由 48 提高到 64，修复长对话中的 400 报错与 AI「失忆」。

## 验证与限制

本次使用本地 Windows 构建发布，未宣称 GitHub Actions 或跨平台发布门禁通过。前端 43 项、桌面后端 48 项自动测试通过，Rust 工作区全量测试与前端生产构建通过。需要真实远端凭据的三项桌面集成测试保持显式忽略。

软件不包含个人服务器、密码、API 密钥或用户数据文件。密码及 API 密钥由当前用户的系统凭据库保存。请同步升级共用该主机库的旧 CLI/TUI/MCP 程序。
