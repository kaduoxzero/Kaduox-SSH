# Kaduox SSH v0.33.0-rc.17 · Windows 文件管理与 AI 运维助手修复

这次发行修复了 rc.16 中 Windows 目标文件管理与 AI 运维助手的多处缺陷，并验证桌面安装包由 Release 流水线全自动附加。

## 下载哪一个？

- `Kaduox-SSH-0.33.0-rc.17-windows-x64-setup.exe`：推荐给 Windows 普通用户。可选择安装位置，包含 WebView2 离线安装组件。
- `Kaduox-SSH-0.33.0-rc.17-windows-x64.exe`：独立 Windows 桌面程序；电脑需已有 WebView2 Runtime。
- `Kaduox-SSH-0.33.0-rc.17-macos-universal.pkg`：macOS 安装包（Intel + Apple Silicon，macOS 11+）。未签名，首次运行请右键应用图标选择“打开”。
- `Kaduox-SSH-0.33.0-rc.17-windows-x64-tools.zip`：kssh、kssh-tui、kssh-fleet、kssh-inventory 命令行工具。
- `kaduox-ssh-mcp.exe`：只需 MCP 接口时单独下载。
- `kaduox-ssh-0.33.0-rc.17-<target>.tar.gz / .zip`：四平台 CLI 套件归档，含清单与 SBOM。
- `SHA256SUMS` / `SHA256SUMS.txt`：分别对应官方四平台资产和桌面附加资产。

## 相对 rc.16 的主要变化

- **Windows 文件管理 Home 按钮修复**：主目录按钮此前总是跳转 Unix 风格的 `/home/<user>`（在 Windows 目标上必然读取失败），现改为使用后端探测到的真实 home（如 `C:/Users/<user>`）；探测失败时回退按惯例拼 `C:/Users/<user>` 并给出提示，不再静默。
- **Windows 路径输入归一**：文件管理路径框支持直接粘贴 `C:\Users\...` 反斜杠路径，自动归一为 SFTP 友好的正斜杠形式；新建/重命名在 Windows 会话拦截 `\` 与 `<>:"|?*` 等非法文件名字符。
- **AI 运维助手工具循环上限生效**：修复工具链回传时轮次计数被重置为 0 的问题，单次提问最多 6 轮命令的防护真正起效，杜绝模型异常时的无限自动执行。
- **AI 会话隔离加固**：切换目标主机或会话时，在途的 AI 请求与命令链自动中止，不再把 A 主机的回答带进 B 主机会话；批准执行期间锁定输入，杜绝两轮并发交错；历史会话中遗留的待批准命令降级为仅展示，不可再误批准；选中未连接主机时给出明确提示。
- **Release 流水线修复**：修复桌面安装包附加 job（attach-desktop）在 attest 跳过后被错误跳过的问题，桌面资产随发布全自动附加，无需手工补传。

## 验证与限制

前端测试、桌面 Rust 测试与发布脚本策略测试全部通过；Release 流水线四平台 CLI 构建、目标级 SBOM、桌面 Windows/macOS 构建与资产校验通过；因 tag 含预发布后缀，按策略跳过原生签名与 GitHub attestation。桌面与 macOS 产物未做平台签名，系统可能提示发行者未知。Windows 目标仍不支持 sudo 提权切换（runas 需交互密码，暂无等价方案）。
