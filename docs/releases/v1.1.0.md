# Kaduox-SSH v1.1.0

**纯内部重构版本**：向 Unix 式可组合性演进，零行为、协议、wire 格式与配置变更。

## 架构变化

### 新增 crate：kaduox-ssh-openssh

OpenSSH 生态解析（`~/.ssh/config` 的 Include/Match、主机目录、inventory、
连接目标解析）从 core 拆出。纯解析、不建立 SSH 会话，可独立复用。

### 新增 crate：kaduox-ssh-transfer

整个传输域（SFTP 引擎、传输策略、remote_fs / remote_mutation / remote_path、
sync、symlink 策略、传输任务注册）从 core 拆出。

因 Rust 孤儿规则禁止跨 crate 的 inherent `impl SshClient`，传输域定义了单方法
`SftpTransport` trait（`open_sftp_for_transfer`），由 core 的 `SshClient` 实现；
原有方法转为泛型自由函数，`SshClient` 保留全部公开方法作为薄壳 facade。
`TransferTaskManager` 改持 `&dyn SftpTransport`，公开类型签名不变。

最终依赖图为无环 DAG：

```
kaduox-ssh-openssh ─┐
                    ├─> kaduox-ssh-core ─> kaduox-ssh-hosts ─> cli / daemon / mcp
kaduox-ssh-transfer ┘
```

### keyring 凭据访问统一

desktop / CLI / MCP 此前各自拼装 keyring service 名与账户字符串，格式漂移会
导致 MCP 静默取不到 desktop 保存的密码。core 新增 `credentials_store` 模块
作为唯一实现（`KEYCHAIN_SERVICE` / `keyring_entry` / `keyring_entry_for_account`
/ `keyring_stored_password`），三端共用；MCP 不再直接依赖 keyring。

### 远端探测脚本共享

MCP 与 desktop 各自内嵌的基础信息/系统指标 shell 与 PowerShell 脚本统一移至
`crates/kaduox-ssh-core/assets/`（`basic_info.sh` / `metrics_compat.sh` /
`metrics.sh` / `metrics.ps1`），经 `include_str!` 编译进二进制并以 core 常量
共享。wire 格式（`__KADUOX_BASIC_INFO_V1__` / `__KADUOX_SYSTEM_METRICS_V1__`）
字节兼容；新增单元测试锁定 marker、LF 行尾与纯 ASCII 内容。

## 兼容性

- 无 breaking change。`kaduox_ssh_core::*` 导出面不变，CLI/TUI/MCP/desktop
  行为一致。
- `release_tool.py` 的 `LOCAL_PACKAGES` 已覆盖全部 7 个 workspace crate。

## 验证

- Rust workspace 全部单元测试通过（core 91 + openssh 50 + transfer 59 +
  hosts/cli/daemon/mcp，总计 300+）；desktop 57+ 通过。
- clippy / fmt 干净；`release_tool.py check` 通过。
- 桌面端（Tauri）编译通过。
