# Kaduox SSH v0.33.0-rc.9 · Windows 桌面预发布版

这次发行提供 Windows x64 原生桌面客户端，以及匹配版本的 CLI/TUI 和 MCP 程序。

## 下载哪一个？

- `Kaduox-SSH-0.33.0-rc.9-windows-x64-setup.exe`：推荐给普通用户。可选择安装位置，包含 WebView2 离线安装组件。
- `Kaduox-SSH-0.33.0-rc.9-windows-x64.exe`：独立桌面程序；电脑需已有 WebView2 Runtime。个人配置保存在当前用户的应用数据目录。
- `Kaduox-SSH-0.33.0-rc.9-windows-x64-tools.zip`：包含 kssh、kssh-tui、kssh-fleet、kssh-inventory，供命令行使用。
- `kaduox-ssh-mcp.exe`：只需 MCP 接口时可单独下载。
- `SHA256SUMS.txt`：下载后核对文件完整性。

本次产物未进行 Authenticode 签名，Windows 可能提示发行者未知。发布范围仅 Windows x64，不包含 Linux/macOS 桌面包。

## 相对 rc.8 的主要变化

### 远程文件

- **文件夹递归下载**：工具栏与右键菜单均支持，远程文件夹按原名保存到所选本地目录；符号链接与特殊文件自动跳过，深度/总量有安全上限。
- **文件操作留痕**：SFTP 上传、下载（含文件夹）、新建、写入、重命名、删除全部写入运行记录，新增黄色「文件」来源徽标。

### AI 运维助手

- **批量批准**：AI 每轮命令最多只询问一次——「批准全部执行 / 全部拒绝」；只读与放行命令仍自动执行，过程折叠为紧凑命令卡片，最终只呈现一个 Markdown 渲染的综合大回答（支持表格、代码块、列表、标题）。
- **分类器更准确**：`2>/dev/null`、`2>&1` 等 stderr 重定向不再误判为写入；`docker ps`/`kubectl get` 为只读，`docker rm`/`kubectl delete` 归删除级。
- **输入区快捷选择**：输入框下方直接切换「请求批准 / 全部权限」和模型；模型列表为按服务商分组的一个大列表，自动从全部已配置服务商获取。
- 设置面板更名为「AI 厂商设置」。

### 终端与体验

- **终端复制粘贴**：右键菜单（复制/粘贴/全选/取消选择），支持 Ctrl+V、Ctrl+Shift+C/V，有选区时 Ctrl+C 复制。
- **磁盘全部展示**：本机显示所有固定盘（固态/机械全部盘符），远程 Linux 显示所有真实挂载点。
- **跳板链可删除**：主机编辑器中选择已有链路即可删除；仍被主机引用时会拒绝并列出占用主机。
- 命令历史面板加宽加高，单台主机最多 500 条，命令最多三行完整显示。
- 移除搜索框旁无实际作用的 Ctrl K 徽标（快捷键本身仍可用）。

## 验证与限制

本次使用本地 Windows 构建发布，未宣称 GitHub Actions 或跨平台发布门禁通过。前端 39 项、桌面后端 41 项自动测试通过，Rust 工作区全量测试与前端生产构建通过。需要真实远端凭据的三项桌面集成测试保持显式忽略。

软件不包含个人服务器、密码、API 密钥或用户数据文件。密码及 API 密钥由当前用户的系统凭据库保存。请同步升级共用该主机库的旧 CLI/TUI/MCP 程序。
