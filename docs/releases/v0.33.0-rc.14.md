# Kaduox SSH v0.33.0-rc.14 · Windows + macOS 桌面预发布版

这次发行首次同时提供 Windows x64 与 macOS（Universal 2）桌面客户端，以及匹配版本的 CLI/TUI 和 MCP 程序。

## 下载哪一个？

- `Kaduox-SSH-0.33.0-rc.14-windows-x64-setup.exe`：推荐给 Windows 普通用户。可选择安装位置，包含 WebView2 离线安装组件。
- `Kaduox-SSH-0.33.0-rc.14-windows-x64.exe`：独立 Windows 桌面程序；电脑需已有 WebView2 Runtime。
- `Kaduox-SSH-0.33.0-rc.14-macos-universal.pkg`：macOS 安装包（同时支持 Intel 与 Apple Silicon，要求 macOS 11+）。双击进入安装向导，自动装入“应用程序”。未签名，首次运行请在访达中右键应用图标选择“打开”。
- `Kaduox-SSH-0.33.0-rc.14-windows-x64-tools.zip`：包含 kssh、kssh-tui、kssh-fleet、kssh-inventory，供命令行使用。
- `kaduox-ssh-mcp.exe`：只需 MCP 接口时可单独下载。
- `kaduox-ssh-0.33.0-rc.14-<target>.tar.gz / .zip`：四个平台的 CLI 套件归档（Linux、macOS Intel、macOS Apple Silicon、Windows），含清单与 SBOM。
- `SHA256SUMS` / `SHA256SUMS.txt`：分别对应官方四平台资产和桌面手工资产，下载后核对完整性。

Windows 与 macOS 桌面产物均未进行平台签名（无 Authenticode / Developer ID 证书），系统可能提示发行者未知。

## 相对 rc.13 的主要变化

- **macOS 桌面版（实验性）**：原生交通灯窗口、macOS 钥匙串凭据存储、ssh-agent 认证路径、⌘K 搜索快捷键。新增 `Desktop macOS installer` CI 流水线：Universal 2 构建、pkg 安装包打包、启动截图验证。
- **macOS 核心测试修复**：测试临时目录改为先 canonicalize，规避 macOS `/var → /private/var` 符号链接触发的防链接策略误伤（仅测试代码变更）。
- **CI 修复**：Linux 各流水线补齐 `libdbus-1-dev`（keyring Secret Service 依赖的系统库）；Release 工具的本地包清单从 2 个 crate 补全为 5 个，SBOM 图校验范围明确为 CLI 发行套件（MCP 为独立 stdio 程序，不在归档内）。
- 界面修复：macOS 顶栏为红绿灯预留拖拽空白区，不再与品牌图标重叠。

## 验证与限制

本次发布首次走通了 tag 触发的完整 Release 流水线：四平台 CLI 构建、目标级 SPDX SBOM、发布资产校验全部通过；因 tag 含预发布后缀，按策略跳过原生签名与 GitHub attestation。macOS 桌面包通过了 CI 编译与截图验证，但未做完整的真机验收（钥匙串授权弹窗、Gatekeeper 提示以真机为准）。需要真实远端凭据的三项桌面集成测试保持显式忽略。

软件不包含个人服务器、密码、API 密钥或用户数据文件。密码及 API 密钥由当前用户的系统凭据库保存（Windows 凭据管理器 / macOS 钥匙串）。请同步升级共用该主机库的旧 CLI/TUI/MCP 程序。
