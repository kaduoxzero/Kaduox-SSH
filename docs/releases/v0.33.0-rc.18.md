# Kaduox SSH v0.33.0-rc.18 · 命令风险分类器与传输正确性加固

这次发行修复命令风险分类器的多处注入绕过、SFTP 递归下载的路径校验缺口、AI 运维助手的并发/审计缺陷，并将 Windows 指标采集切换到 stdin 脚本通道。

## 下载哪一个？

- `Kaduox-SSH-0.33.0-rc.18-windows-x64-setup.exe`：推荐给 Windows 普通用户。可选择安装位置，包含 WebView2 离线安装组件。
- `Kaduox-SSH-0.33.0-rc.18-windows-x64.exe`：独立 Windows 桌面程序；电脑需已有 WebView2 Runtime。
- `Kaduox-SSH-0.33.0-rc.18-macos-universal.pkg`：macOS 安装包（Intel + Apple Silicon，macOS 11+）。未签名，首次运行请右键应用图标选择“打开”。
- `Kaduox-SSH-0.33.0-rc.18-windows-x64-tools.zip`：kssh、kssh-tui、kssh-fleet、kssh-inventory 命令行工具包。
- `kaduox-ssh-mcp.exe`：只需 MCP 接口时单独下载。
- `kaduox-ssh-0.33.0-rc.18-<target>.tar.gz / .zip`：四平台 CLI 套件归档，含清单与 SBOM。
- `SHA256SUMS` / `SHA256SUMS.txt`：分别对应官方四平台资产和桌面附加资产。

## 相对 rc.17 的主要变更

- **命令风险分类器注入绕过修复**：后台执行符 `&` 此前不被识别为分隔符，`sleep 1 & rm -rf /` 可逃逸分级；`$(...)`、反引号、`<(...)`、`>(...)` 子 shell 语法现在一律保守升级为危险命令（良性用法如 `echo $(date)` 也会被拦截，代价是多一次人工批准）；`rm` 判定重写为跨参数累计 `-r/-R/--recursive` 与 `-f/--force`，`rm -r -f /`、`rm --recursive --force /var`、`rm /home -rf` 等写法全部命中。
- **SFTP 递归下载路径校验**：服务端返回的非法条目名（含 `\`、`/`、控制字符、盘符冒号）不再直接拼接本地路径，而是计入 skipped 并记录；Windows 远端目录的本地根目录名按 `/` 和 `\` 双分隔符切分并校验，拒绝盘符残留。
- **AI 运维助手并发与审计**：消息渲染保留原始下标，批准/复制不再因过滤 tool 消息而错位；忙碌锁覆盖整条工具链，杜绝执行期间并发提交新一轮导致的链互踩；链中途中断时已执行的命令结果先落盘审计再退出；切换目标或会话时界面正确解锁；历史遗留待批准卡片依旧仅展示。
- **Windows 指标采集 stdin 化**：基础信息与系统指标脚本改经 `powershell -Command -` 的 stdin 传入，退役 `-EncodedCommand`，解除命令行长度上限与编码隐患；采集失败时错误信息附带 stderr 尾部片段，便于定位。
- **传输正确性**：断点续传偏移逻辑提取为纯函数并补齐五态单测，去掉掩盖脏尾部的 `.min(total)`；exec 通道在超时/取消时显式关闭，不再泄漏服务端进程；主机库显式配置的平台类型永远优先于探测结果；递归传输结束显式关闭 SFTP 会话；上传悬空符号链接给出明确提示。
- **杂项**：新建/重命名拒绝 `.` 与 `..`；右键菜单坐标下限钳制；数据屏 effect 依赖补全；AI 页窄窗口下会话列表改顶部横排。
