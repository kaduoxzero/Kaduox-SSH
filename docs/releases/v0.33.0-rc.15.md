# Kaduox SSH v0.33.0-rc.15 · Windows 目标主机支持

这次发行新增对 **Windows OpenSSH 目标主机** 的支持，桌面客户端同时提供 Windows x64 与 macOS（Universal 2）版本。

## 下载哪一个？

- `Kaduox-SSH-0.33.0-rc.15-windows-x64-setup.exe`：推荐给 Windows 普通用户。可选择安装位置，包含 WebView2 离线安装组件。
- `Kaduox-SSH-0.33.0-rc.15-windows-x64.exe`：独立 Windows 桌面程序；电脑需已有 WebView2 Runtime。
- `Kaduox-SSH-0.33.0-rc.15-macos-universal.pkg`：macOS 安装包（Intel + Apple Silicon，macOS 11+）。未签名，首次运行请右键应用图标选择“打开”。
- `Kaduox-SSH-0.33.0-rc.15-windows-x64-tools.zip`：kssh、kssh-tui、kssh-fleet、kssh-inventory 命令行工具。
- `kaduox-ssh-mcp.exe`：只需 MCP 接口时单独下载。
- `kaduox-ssh-0.33.0-rc.15-<target>.tar.gz / .zip`：四平台 CLI 套件归档，含清单与 SBOM。
- `SHA256SUMS` / `SHA256SUMS.txt`：分别对应官方四平台资产和桌面手工资产。

## 相对 rc.14 的主要变化

- **Windows 目标主机支持**：连接运行 Windows OpenSSH 服务器的机器。连接时自动探测目标系统（也可在主机编辑里手动指定），主机卡片显示 Windows 徽标。
- **Windows 终端**：交互终端使用 cmd.exe（Windows PowerShell 5.1 在 ConPTY-over-SSH 下不产生输出，为实测后的兼容性取舍）；非交互命令可正常执行 `powershell -Command ...`。
- **明确的边界**：Windows 目标暂不支持 sudo 提权切换（会给出明确错误而非静默失败）、远程文件管理和系统信息面板，三者将在后续版本适配。
- **CI 新增** Windows loopback OpenSSH 集成测试：真实 sshd 上验证 exec、sudo 拒绝和 cmd PTY 回显。

## 验证与限制

Release 流水线四平台 CLI 构建、目标级 SBOM、资产校验全部通过；因 tag 含预发布后缀，按策略跳过原生签名与 GitHub attestation。Windows 目标路径经过本机 loopback OpenSSH 服务器实测（探测、exec、sudo 拒绝、cmd PTY 回显）。桌面与 macOS 产物未做平台签名，系统可能提示发行者未知。

软件不包含个人服务器、密码、API 密钥或用户数据文件。密码及 API 密钥由系统凭据库保存（Windows 凭据管理器 / macOS 钥匙串）。请同步升级共用该主机库的旧 CLI/TUI/MCP 程序。
